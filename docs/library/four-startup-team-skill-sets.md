# The 4 Start-Up Team Skill Sets

The source article this vault is built on. Sergio Marrero argues that the usual
hipster / hacker / hustler trio is missing a fourth skill set: the **hound**, the
researcher, whose job is to keep the team focused on what the user actually
wants instead of falling in love with a solution.

His key framing, and the reason it works for one person: treat each role as an
**archetype**, a set of skills the team needs depth in — not a person you must
hire. One developer can wear all four, one at a time.
