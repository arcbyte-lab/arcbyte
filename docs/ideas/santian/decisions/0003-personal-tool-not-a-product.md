## Decision

Santian is built for the owner's own use. It is not a product aimed at
strangers, and there is no positioning, pricing, or channel to work out.

## Context

[Why would anyone switch from Google Tasks?](../hustler/why-switch-from-google-tasks.md)
assumed a stranger currently on Google Tasks who needs a reason to move. Asked
directly, the owner's answer was: nobody needs to. This is for him.

## What each lens said

- **Hound:** [who plans their day by the clock?](../hound/who-plans-their-day-by-the-clock.md)
  worried the whole idea rested on one developer's own habit, with no input from
  a real person. That is no longer a gap to close — the owner is the only user
  this needs to be right for. The question is still worth answering, but as
  self-knowledge, not market research.
- **Hipster:** unaffected. The design still has to work for one real person
  using it daily, which is a real design bar, not a lower one.
- **Hacker:** unaffected. Nothing about the data model or storage changes
  because there is one user instead of many.
- **Hustler:** this lens is now mostly closed for this idea. No pricing, no
  channel, no positioning line. The only hustler-shaped question left is
  survival: does the owner keep using it after the novelty wears off.

## Options rejected

- **Treat it as a product with one very specific early user (the owner).**
  Rejected — that framing would push toward acquisition, pricing, and
  positioning work with no audience to spend it on. Better to say plainly there
  is no market goal, so effort doesn't drift toward decorating a case for
  strangers who don't exist yet.

## What this does not decide

Whether Santian is ever opened up to other people later. That is a future
question, not a current one, and nothing here forecloses it.

## How we will know we were wrong

If the owner starts asking hustler-shaped questions again — pricing, a landing
page, "how would someone else find this" — that is a signal the goal quietly
changed back to a product, and this decision should be revisited.
