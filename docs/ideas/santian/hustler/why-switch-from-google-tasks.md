## The question
The design notes aim to feel like Google Tasks. Google Tasks is free, already
installed, and synced. What does this app do that makes leaving it worth the
trouble?

## Why it matters
If the honest answer is "nothing yet, the clockface is the bet", then the
clockface is the product and the task list is scaffolding — and the build order
in [offline task module architecture](../hacker/offline-task-module-architecture.md)
is backwards.

## How I could answer it
- Cheapest way: write the one-line pitch. If it describes a task list, there is
  no answer yet.
- Best way: put the clockface in front of someone who already uses Google Tasks
  and watch whether they lean in.

## Answer
The question doesn't apply. Santian is a personal tool for the owner, not a
product aimed at strangers who currently use Google Tasks. There is no one to
switch — see
[0003 — Santian is a personal tool, not a product](../decisions/0003-personal-tool-not-a-product.md).

The build-order concern raised above is separately settled — see
[0002 — build Tasks before Clockface](../decisions/0002-build-tasks-before-clockface.md).
