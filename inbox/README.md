# Inbox

Dump raw model output here when you do not want to stop and file it properly.

Two rules: put the model name and surface in the first line of the file, and
empty this folder every week. If a note sits here for more than a month, it was
not important — move it to `../archive/`.

An AI should not leave things here. File them properly, or ask which lens they
belong to. See [SCHEMA.md](../SCHEMA.md).
